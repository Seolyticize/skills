# Ranking patterns: cause and action

| Pattern                                              | How to confirm                                                            | Likely cause                                                                      | What to do                                                                                                                                                                                     |
| ---------------------------------------------------- | ------------------------------------------------------------------------- | --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Drop with a different page ranking                   | `get_url_swaps`, `get_rank_history` (page per day)                        | Cannibalisation, a canonical change, or internal links pointing at the wrong page | Choose the owner (`get_cannibalization` shouldOwn), point internal links and the canonical at it, merge or re-target the other page, and register it with `set_keyword_owners` (dry run first) |
| Two pages taking turns                               | `get_url_swaps` flags it                                                  | Google cannot tell which page is meant                                            | Merge, or make their intents clearly distinct                                                                                                                                                  |
| Steady position, clicks down                         | `get_serp_features`, `get_serp_intent_shifts`, `get_zero_click_estimates` | An AI Overview, snippet, video or shopping block arrived above                    | Target the feature: answer format, schema, video. Check citation with `get_ai_overview_citations`. Adjust click forecasts.                                                                     |
| Results page changed type                            | `get_serp_intent_shifts`                                                  | Google now wants another kind of page (informational to commercial, say)          | Run `get_sxo_gap` on the ranking page. Change the page type, or add a page of the type that now ranks.                                                                                         |
| Many keywords drop on one day, industry too          | `get_serp_volatility`, `list_annotations` with Google updates             | A Google update                                                                   | Wait a week or two. Then compare winners and losers by page type and E-E-A-T before acting.                                                                                                    |
| Many keywords drop, industry calm                    | `get_search_anomalies`, `list_annotations`, `get_seo_changes`             | A deploy or technical regression (noindex, 404, canonical, robots)                | Hand over to technical work. Check `check_deploy` and the crawl.                                                                                                                               |
| One keyword slides slowly, newer pages above         | `get_competitor_page_changes`, `get_freshness_queue`                      | A rival improved, or the results page moved to fresher content                    | Refresh the page. Brief it with `build_content_brief` and `targetUrl`.                                                                                                                         |
| A new domain enters the top 20                       | `get_serp_newcomers`                                                      | A new competitor or a new content push                                            | Watch it. Add it with `add_competitors` if it persists.                                                                                                                                        |
| Ranks well, not cited in AI Mode or AI Overviews     | `get_tracker_ai_mode` (paid), `get_ai_overview_citations`                 | The page is not written to be quoted, or others are trusted more                  | `get_geo_readiness` on the page, and `get_ai_citation_gap` against a cited page                                                                                                                |
| Mobile drops, desktop holds                          | `get_rank_history` and `get_position_distribution` per device             | Mobile UX, rendering or page-experience issues, or a mobile-only feature          | `get_sxo_gap` with `deep: true` (phone render), `get_vitals_history`                                                                                                                           |
| Desktop drops, mobile holds                          | Same, per device                                                          | Often a desktop-only feature or layout. Check the results pages.                  | Compare features per device with `get_serp_features`                                                                                                                                           |
| Keyword shows "not captured"                         | `get_rank_history` (missing days), `get_run_status`                       | The capture failed or was skipped. This is not a ranking change.                  | Read the run's reason. Refresh only if needed (paid).                                                                                                                                          |
| Average position improves while page-one count falls | `get_position_distribution`                                               | Weak keywords fell out, so the average covers fewer keywords                      | Report the counts, not the average                                                                                                                                                             |

## Local trackers

For trackers with a city or postcode location, a map pack above the results changes everything. `get_local_visibility` (free) and `run_local_grid_scan` (paid; quote first) show map-pack position across an area. Organic rank alone understates or overstates local reach.

## Reporting language

- "Not in the results": the page was read and the client was absent.
- "Not captured": nobody read the page that day.
- "Likely cause": evidence that points one way. "Confirmed" is only for a cause you can show, such as a page swap or a deploy that made a page noindex.
